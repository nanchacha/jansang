# Status item atlas — v1

Built with the built-in image_gen tool using assets/concepts/stats-hud-orb-v1.png as style reference.

Runtime asset: assets/ui/status-items-v1.png. Transparent PNG, three equal square cells from left to right: sword, potion, cracked shield. Numbers and life orb are rendered by HTML/CSS so they reflect live expedition state. Artwork is decorative; accessible stat labels remain in the DOM.

## Final prompt

Use case: stylized-concept.
Asset type: production UI icon sprite atlas, transparent PNG, EXACTLY 3:1 wide canvas.
Input image: style reference for the selected JANSANG game HUD, NOT a screenshot to reproduce.
Create exactly THREE separate inventory icons aligned on ONE horizontal row in THREE equal square cells on a truly TRANSPARENT background. No frame, no slot backgrounds, no text, no numbers, no badges, no life orb. Each object centered in its own equal-width square cell with at least 12% transparent padding on all four sides and no overlap across cells.
Left cell: the reference's single diagonal straight medieval sword, pommel toward bottom left, steel blade tip toward top right, weathered antique bronze crossguard and leather grip, clean silhouette.
Middle cell: the reference's round green healing potion, distinct thin bottle neck, bronze/gold cork, translucent olive-green glass with softly glowing yellow-green liquid, beautifully rendered facets and highlights. It must read as a bottle not a crystal ball.
Right cell: a single dark steel medieval heater shield with antique bronze rim and a clearly visible deep jagged crack down the center, like the cumulative-hit icon in the reference.
Art style: polished painterly realistic dark-fantasy UI item illustrations, strong readable silhouettes at 64px, matching the reference. Metal highlights warm ivory, no colored background, no cartoon outlines. Fill each cell consistently, icons large enough to read. Preserve genuine alpha transparency; no checkerboard painted into the image. 1536x512 canvas preferred.
