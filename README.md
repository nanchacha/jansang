# 잔상 · AFTERIMAGE

스토리 없이 보스 전투에 집중한 모바일 웹 프로토타입입니다. 턴마다 공격하고, 보스의 공격 순간에 탭해 피해를 완전히 막습니다. Canvas 배경에 투명 PNG 캐릭터를 합성하며 게임 엔진·빌드·패키지 설치가 필요 없습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더를 열고 실행합니다.

```sh
node server.mjs
```

PC: http://localhost:4173

휴대폰: PC와 같은 Wi-Fi에 연결하고 터미널에 출력된 `Mobile on same Wi-Fi` 주소로 접속합니다. PC 방화벽이 Node.js의 로컬 네트워크 연결을 허용해야 합니다. 서버는 게임 파일 5개와 캐릭터 PNG 2개만 제공합니다. 앱스토어 설치용 APK/IPA가 아닌 브라우저 프로토타입입니다.

## 캐릭터 디자인

`assets/concepts/hollow-warden-v1.png`와 `protagonist-v1.png`를 보스와 주인공에 적용합니다. 전신 시안의 몸체와 좌우 팔·무기를 Canvas에서 나눠 그리는 2D 컷아웃 애니메이션입니다. 보스는 공격하는 팔만 들어 올린 뒤 내려베기·횡베기·찌르기·끌어올리기를 수행하며, 양손 공격은 두 팔이 함께 움직입니다. 준비·지연·페인트·휘두르기·복귀를 전투 시계에 맞추고, 근접 공격은 타격 시점에, 원거리는 발사 시점에 검이 공격 자세에 도달합니다. 원거리 충전은 손을 따라가며 발사 후 탄의 출발점은 고정됩니다. 주인공은 검을 들어 공격하고 패링 때 검을 몸 앞에 올리며, 피격 시 몸을 젖힙니다. 대기 중에는 호흡과 팔의 작은 움직임이 있습니다.

팔·검의 발광도 움직이는 에셋을 따라갑니다. 공격 방향은 공격하는 쪽 어깨·팔·검날의 빛으로 읽으며, 전투 화면에 방향 표지나 화살표를 띄우거나 패링 버튼을 미리 강조하지 않습니다. 원본 PNG는 그대로 사용하고 어깨를 중심으로 팔·검을 함께 움직이는 방식으로, 팔꿈치별 리깅이나 다른 시점의 그림은 포함하지 않습니다. 동작 줄이기 설정에서는 새 모션을 생략하고 필수 발광·투사체를 유지합니다. 이미지를 불러오지 못하면 기존 도형 캐릭터를 표시합니다. 원본과 생성 프롬프트는 `assets/concepts/`에 보관합니다.

## 조작

- **공격 / J**: 내 차례에 공격합니다. 공격 뒤에는 보스 차례가 됩니다.
- **왼쪽 패링 / A**, **오른쪽 패링 / D**: 화면 기준으로 공격이 오는 쪽 버튼을, 보조 원이 안쪽 원에 닿을 때 누릅니다. 근접 공격의 원은 보스 가슴에, 원거리 공격의 원은 플레이어 앞에 표시됩니다.
- **팔과 무기의 발광**: 현재 타격의 준비 동작이 시작되면 공격하는 쪽 어깨·팔·검이 빛나고, 판정 시간에는 더 밝은 금빛으로 바뀝니다. 화면 왼쪽은 파랑, 오른쪽은 주황이며 양손 공격은 두 팔과 검이 함께 빛납니다. 원거리 탄도 같은 방향 색상을 사용합니다. 패링 성공 직후 발광은 사라지고 다음 준비 동작 전에는 다음 공격을 공개하지 않습니다. 타이밍 가이드를 꺼도 발광은 유지합니다. 방향 문구·화살표·버튼 자동 강조는 사용하지 않으며 버튼의 이름과 기본 색은 조작 구분용입니다.
- **양손 공격 / A+D**: 두 버튼을 두 손가락으로 함께 누릅니다. 두 누름의 간격은 최대 80ms이며, 첫 버튼을 누른 상태에서 두 번째를 눌러야 합니다. 두 입력 모두 타격의 패링 시간 안에 들어와야 합니다. 마우스 하나로 양손 공격을 막으려면 키보드 A+D를 사용하세요.
- **새 입력이 필요합니다**: 버튼을 계속 누르고 있어도 다음 타격을 자동으로 막지 않습니다. 각 연속 타격마다 손을 떼고 새로 누르세요. 한 손 공격에 양쪽을 함께 누르거나 방향을 틀리면 실패합니다.
- **퍼펙트**: 정확한 패링을 별도 연출과 기록으로 표시합니다. 일반·퍼펙트 패링 모두 피해를 전부 막으며, 보스에게 피해를 주지 않습니다. 보스 체력은 직접 공격할 때만 줄어듭니다.
- **일시 정지 / Esc**: 전투를 멈춥니다. 탭 전환·창 포커스 이탈·300ms 초과 프레임 중단에도 자동 정지합니다.
- **연습 모드**: 시작 전에 선택합니다. 생명력 무제한, 넓은 패링 판정이며 최고 기록에서 제외됩니다.
- **연습할 공격**: 연습 모드에서 16종 중 하나를 선택하면 그 공격만 한 묶음씩 반복합니다. 전체 무작위 조합도 선택할 수 있습니다. 전투를 시작하기 전에 설정합니다.
- **타이밍 가이드**: 보조 원을 끌 수 있습니다. 보스 동작과 팔·검·가슴의 발광 신호는 계속 보입니다.

## 전투 규칙

보스의 공격 턴마다 개별 공격 컴포넌트를 새로 조합합니다. 스테이지별 고정 패턴이나 미리 만든 연속 공격 목록은 사용하지 않습니다.

- **조합 수:** 매 턴 1~4개 컴포넌트 무작위. 연속 교차검·교차 파동 연사는 컴포넌트 하나가 2~3타이며, 전체 턴은 최대 6타입니다.
- **공격 동작:** 내려베기, 횡베기, 찌르기, 도약 강타, 회전 베기, 끌어올리기, 지면 파동, 붉은 강타, 태엽 꺾기, 파고들기, 후퇴 후 찌르기, 연속 교차검, 낮은 쓸기, 에너지 탄, 교차 파동 연사, 쌍방향 에너지 파동 중 선택합니다.
- **사용하는 손:** 매 컴포넌트의 시작 손을 왼손 / 오른손 중 독립적으로 선택합니다. 연속 교차검과 교차 파동 연사는 묶음 안에서 손을 번갈아 사용합니다. 교차 공격과 같은 손 연타 모두 가능합니다.
- **리듬:** 일반 컴포넌트는 바로 준비해서 공격(55%) / 검을 들고 지연(30%) / 거짓 동작 후 공격(15%). 끌어올리기·붉은 강타는 긴 지연, 태엽 꺾기는 페인트, 돌진·후퇴·연속 교차검은 바로 준비하는 동작으로 성격을 구분합니다. 각 구간의 길이는 매번 달라집니다.
- **시간:** 동작별 준비 시간, 지연 길이, 타격 사이 회복 간격도 무작위.
- **이동:** 각 타격마다 기본 자세 / 상승 후 하강 / 낮게 내려갔다 상승 / 멀어졌다 돌진 / 떠오르며 멀어진 뒤 급강하 중 하나를 독립적으로 선택합니다. 이동 폭도 85~115%로 변합니다. 원근에 따라 몸체·검·그림자 크기가 바뀌며, 기존 공격 고유의 이동과 겹쳐집니다. 연습 모드에서 같은 공격을 골라도 이동은 달라집니다.

이동은 타격 시점과 같은 시계를 사용합니다. 일시 정지·패링 입력으로 경로나 타격 시간을 다시 뽑지 않으며, 성공한 이른 패링도 진행 중인 이동을 끊지 않습니다. 화면 크기에 맞춰 이동과 확대를 제한해 보스의 신호가 체력 표시나 화면 밖으로 가려지지 않게 합니다. OS의 동작 줄이기 설정에서는 이동·원근 변화를 생략합니다.

예를 들어 한 턴에 `오른손 찌르기 → 왼손 지연 내려베기 → 왼손 페인트 횡베기`가 생성될 수 있습니다. 같은 손 순서라도 동작과 리듬은 달라집니다. 우연히 같은 조합이 다시 나올 수 있습니다.

두 페이즈에서 모든 컴포넌트를 사용합니다. 체력이 50% 이하가 되면 다음 턴부터 준비·지연 시간을 줄이되 최소 대응 시간을 지킵니다. 한 턴의 조합은 시작할 때 확정하며, 패링 입력이나 도중 페이즈 변화로 타격 시점·손·동작을 바꾸지 않습니다. 좌우는 화면 기준입니다. 도약·돌진·후퇴는 보스 위치가 움직이며, 회전·낮은 쓸기·끌어올리기는 다른 검 궤적, 지면 파동은 바닥을 따라 접근하는 원으로 표현합니다. 붉은 강타는 **좌우 동시 패링이 필요한 하나의 타격**, 연속 교차검은 **매 타격의 방향에 맞춘 별도 입력**입니다. 지면 파동도 빛나는 팔과 검이 있는 쪽을 패링합니다. 정확한 방향과 타이밍을 맞추면 일반 패링도 피해를 완전히 막습니다.

원거리 3종은 보스가 뒤로 물러나 작아진 뒤 충전하고 발사합니다. 비행 중에는 거리를 유지하며, **발사 순간에는 판정이 없고 플레이어에게 도착할 때만 패링**합니다. 에너지 탄은 커지는 구체 한 발, 교차 파동 연사는 좌우로 번갈아 오는 2~3발, 쌍방향 에너지 파동은 두 궤적이 동시에 도착하는 하나의 타격입니다. 좌우 파동은 각각 플레이어의 왼쪽·오른쪽으로 돌아 들어옵니다. 비행 시간은 매번 달라지지만 최소 620ms를 보장합니다. 양쪽 파동은 좌우 동시 패링으로 막고, 패링해도 보스 체력은 줄지 않습니다. 동작 줄이기 설정에서도 판정에 필요한 투사체 이동은 표시합니다.

모든 타격은 동일한 피해 방지 판정을 거칩니다. 방어 불가 공격, 필수 피해, 랜덤 적중 판정은 없습니다. 매 타격에 최소 620ms의 최종 준비 동작을 보장합니다. 이전 타격의 동작과 늦은 패링 판정이 끝난 뒤 다음 준비 동작이 시작됩니다. 연속 공격 간격은 패링 입력 대기와 양쪽 판정 여유보다 깁니다. 연타하면 320ms 동안 다시 패링할 수 없어 정확한 타이밍을 익혀야 합니다.

방향 판정을 위해 첫 누름을 최대 80ms 모읍니다. 손을 떼면 한쪽 입력으로 확정합니다. 판정에는 처음 누른 시각을 사용하므로 판정 끝에서 누른 입력도 유효합니다. 양손 퍼펙트는 두 누름 모두 퍼펙트 구간에 들어와야 합니다. 패링은 보스 체력을 줄이지 않습니다.

## 검증

```sh
node --test combat.test.mjs
```

400개 전투(200개 난수 시드 × 2개 모드)의 무피격 클리어, 두 페이즈의 전체 컴포넌트·리듬·타격 수 등장, 양손 조합, 판정 경계, 연타 제한, 피격 중복 방지, 패배·재시작을 검증합니다. 추가로 4,000개 무작위 공격 턴(1,000개 시드 × 2개 모드 × 2개 페이즈)에서 매 타격의 준비 시간, 확정된 조합 유지, 판정 경계 부근의 연속 패링을 검증합니다. 16종 × 양손 × 2개 모드 × 2개 페이즈의 128개 조합에서 일반 패링으로 피해를 전부 막는지, 연속 공격의 타격별 입력과 연습용 선택이 도전 모드에 영향을 주지 않는지도 검증합니다. 화면 표현과 전투 판정은 분리되어 있습니다.

좌우 오입력, 한 손 공격에 동시 입력, 양손 입력의 80ms 경계·누름 겹침·두 타이밍의 유효 구간, 누르고 있기와 재시작도 검증합니다.

원거리 3종은 발사·도착 시각 분리, 최소 비행 시간, 비행 중 보스 거리 유지와 복귀, 발사 때 입력 실패, 도착 때 피해 0과 보스 체력 유지도 검증합니다.

캐릭터 모션은 공격하는 팔만 움직이는지, 타격·발사 시각에 공격 자세에 도달하는지, 준비·타격·복귀 경계가 연속인지, 이른 패링이 모션을 끊지 않는지, 동작 줄이기와 주인공의 공격·방어 후 복귀를 추가로 검증합니다. 현재 테스트는 총 14개입니다.
